Install APK

      
The file is pushed to /data/local/tmp, installed with
        pm install -r, then removed. It comes from this computer or from the copies this
        checkout caches under apks/ — a page in a browser cannot download from hosts such as
        GitHub, which send no cross-origin headers.

      

        
        
      

      
Installed by you

      

      
Recommended for TV

      

      
"Installed by you" is the device's own third-party list (pm list packages
        -3) — every package on it is listed by its id, because this Android version exposes no app
        name over ADB (no application-label in its package dump, no aapt on the
        box). Open a row's Details for its version, sizes and permissions.

        A recommendation installs the copy this checkout carries under apks/:
        python3 refresh_apks.py resolves each project's newest release, keeps the asset that
        runs on one instruction set (--abi, default: the connected box) and rewrites
        apks/index.json. An Install button appears only where that file is actually present, and
        the button names the file — there is no link for anything to follow. The layout tag comes from each
        cached APK's own manifest: a Leanback launcher entry is what puts a tile on the TV home screen.
