Chips: verdict from the toolkit's notes (bloat / careful / keep / undocumented) and why the
      risk class was derived — uid, partition, system role, installer, running process, and for an overlay the
      package it actually rewrites, read from the device rather than from its name. Disabling is per-user and
      reversible with Re-enable. Core and overlay packages are refused unless you tick the override. The
      Disabled filter lists everything currently switched off on the device, including packages that were
      disabled outside this tool.

Install APK

      
Pushed to /data/local/tmp, installed with pm install -r, then
        removed. A GitHub link is read through the Releases API and resolved to the asset built for this box.

      

        
        
      

      

        
      

      
Recommended for TV

      

      
Every row installs the newest published release rather than a pinned file, and picks the
        APK whose instruction set this box runs — the same row gives a 32-bit stick and a 64-bit stick different
        files. The tag says whether the developer ships a TV home-screen entry (a Leanback launcher in the
        manifest, read out of each APK on 2026-10-08) or only a phone layout.

    


    

      
Launcher

      
Current default home activity, read from the HOME role. Only disable the stock launcher
        after a replacement is installed and confirmed working.
